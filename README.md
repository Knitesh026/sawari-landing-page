awaRI
SawaRI is a modern ride-hailing and parcel delivery platform designed for seamless, reliable, and safe transportation across India. This project includes a responsive landing page, user onboarding, driver registration, and more.
🚀 Features
Instant Ride Booking: Book cabs and rides in real-time.
Parcel Pick-up & Delivery: Send and receive parcels with ease.
Responsive UI: Mobile-first, modern design using React and Tailwind CSS.
Waitlist & Driver Registration: Join as a user or register as a driver.
Multi-language Support: Easily switch between supported Indian languages.
Privacy & Security: GDPR-compliant privacy policy and secure data handling.
Admin Dashboard: Manage drivers, waitlist, and platform operations.
🖥️ Tech Stack
Frontend: React, TypeScript, Tailwind CSS
Routing: React Router
State Management: React Context API
Icons: Lucide React
Build Tool: Vite
